Nexora API - Orientación Vocacional (0.2.0)

Download OpenAPI specification:

Equipo de Arquitectura de Software Nexora: contacto.nexora@ejemplo.edu.ec URL: https://github.com/enriqueherreraec/nexora-arquitectura License: MIT

Contrato formal OpenAPI para el Sistema Web de Orientación Vocacional Nexora. Define las cuatro operaciones fundamentales del alcance arquitectónico acordado: autenticación de estudiantes, registro transaccional de evaluaciones Likert, consulta de resultados vigentes y despacho del informe PDF por correo electrónico.

Autenticación

Gestión de sesiones e inicio de sesión de estudiantes y usuarios del sistema.

Iniciar sesión con correo y contraseña

Valida las credenciales del estudiante contra el repositorio seguro y retorna un token JWT de tipo Bearer junto con los datos del usuario autenticado.

Request Body schema: application/json
required

Credenciales de acceso del usuario registrado.

email
required
string <email> <= 120 characters

Correo electrónico institucional o personal registrado.

password
required
string [ 8 .. 100 ] characters

Contraseña de la cuenta del estudiante.

Responses

Servidor de desarrollo local FastAPI

http://localhost:8002/api/v1/auth/login

Servidor de simulación Mock Prism

http://localhost:4010/api/v1/auth/login

Evaluaciones

Registro transaccional de respuestas Likert y consulta de afinidades vocacionales.

Enviar respuestas del cuestionario y generar evaluación vocacional

Procesa exactamente 20 respuestas en escala Likert (valores de 0 a 4), calcula las puntuaciones en 10 áreas vocacionales, determina las carreras sugeridas y persiste el intento en PostgreSQL de forma atómica.

Authorizations:
bearerAuth
Request Body schema: application/json
required

Diccionario con las 20 respuestas Likert indexadas por el número de pregunta (1 a 20).

required
object

Mapa de respuestas con exactamente 20 elementos, donde las claves son cadenas del "1" al "20" y los valores enteros Likert de 0 a 4.

Responses

Servidor de desarrollo local FastAPI

http://localhost:8002/api/v1/evaluaciones

Servidor de simulación Mock Prism

http://localhost:4010/api/v1/evaluaciones

Consultar la última evaluación realizada por el estudiante autenticado

Informes

Generación y despacho seguro de informes vocacionales oficiales en PDF adjunto.

Despachar informe vocacional en PDF al correo de la cuenta

Verifica la propiedad estricta del recurso sobre el identificador de la evaluación, genera en memoria el informe oficial en formato PDF mediante ReportLab y despacha el documento adjunto hacia la dirección de correo registrada mediante SMTP.

Authorizations:
bearerAuth
path Parameters
id
required
integer >= 1
Example: 501

Identificador numérico único de la evaluación a despachar.

Responses

Servidor de desarrollo local FastAPI

http://localhost:8002/api/v1/informes/{id}/enviar-correo

Servidor de simulación Mock Prism

http://localhost:4010/api/v1/informes/{id}/enviar-correo
